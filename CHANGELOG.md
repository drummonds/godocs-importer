## [0.1.0] - 2026-02-15

### Added
- ENEX XML parser with streaming support
- Import tracker using pglike for idempotent imports
- godocs HTTP client (upload, tags, dimensions, job polling)
- CLI with `walk`, `check`, and `import` subcommands
